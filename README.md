### 02. Full-Stack E-Commerce Recommendation Pipeline

*Recommendation Systems · Learning to Rank · MLOps*

An industrial-style, multi-stage recommendation pipeline designed around a **retrieval → scoring → ranking** architecture.

**Planned architecture**
- **Retrieval:** Seven-channel candidate generation, aggregation, and deduplication
- **Scoring / pre-ranking:** LambdaMART implemented with LightGBM
- **Fine ranking:** DeepFM for personalized ranking and feature interactions

**Engineering scope**
- Data processing and feature engineering
- Model training and offline evaluation
- Experiment tracking and reproducibility
- Cloud infrastructure and deployment
- Production-oriented ML workflows

**Status:** Under development
